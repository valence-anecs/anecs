# Security policy

## Supported versions

ANECS has not issued a production release. Security fixes apply to the current `main` branch.

## Reporting

Do not open a public issue for vulnerabilities, leaked credentials, private supplier data or identity-resolution defects that could expose a real organization. Use GitHub private vulnerability reporting when enabled, or contact the organization owner through a private channel.

## Sensitive data

- Do not commit credentials or API keys.
- Do not commit unlicensed source documents.
- Do not commit personal data or private commercial correspondence.
- Use synthetic or anonymized fixtures in the public repository.
- Treat false identity merges as security-relevant economic integrity defects.
